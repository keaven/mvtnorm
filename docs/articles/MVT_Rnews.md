# Using mvtnorm

This page makes the original Sweave vignette available from the pkgdown
Articles index. The source vignette remains `vignettes/MVT_Rnews.Rnw`;
the PDF is the installed vignette returned by:

``` r
vignette("MVT_Rnews", package = "mvtnorm")
```

[Open the original PDF
vignette](https://keaven.github.io/mvtnorm/articles/MVT_Rnews.pdf)
