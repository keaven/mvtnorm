# Articles

### Deterministic QMC

- [Deterministic QMC
  Methodology](http://mvtnorm.R-forge.R-project.org/articles/dqmc-methods.md):

  Methodological comparison of mvtnorm’s randomized, deterministic grid,
  original QMC, and new deterministic QMC algorithms.

- [Speed and Accuracy
  Comparison](http://mvtnorm.R-forge.R-project.org/articles/dqmc-benchmark.md):

  Reproducible benchmark comparing default GenzBretz, Miwa, fixed-budget
  original randomized QMC, and the new deterministic QMC backend.
